# Plan: Sidecar Library Refactor

## Terminal Goal

All sidecar lifecycle operations exist in exactly one place. No duplicated logic across scripts. Loop scripts generated by code generators, not heredocs. The library is the incremental path toward the sidecar-manager.

## Design Principles

1. **One function, one truth.** Every operation that exists in multiple places today becomes a single function in `nbs-sidecar-lib.sh`.
2. **Code generators, not heredocs.** Loop scripts are built line-by-line by generator functions using arrays and locals. The generated script is written to a temp file, piped to bash, and available for debugging. No nested escaping.
3. **Bash done properly.** Locals everywhere. Associative arrays for config. Indexed arrays for argument lists. Proper quoting. No global state leakage. Functions return status codes and write results to named variables via `printf -v`.
4. **Each step is a refactor, not a behaviour change.** Tests keep passing after every commit.

## File Structure

```

bin/nbs-sidecar-restart          # Existing — migrated to use library
```

## Library API

### Process Discovery

```bash
# Check if a PID's cmdline contains a flag value.
# Uses tr '\0' '\n' — single implementation, no grep -qz.
nbs_sc_cmdline_has <pid> <flag>
# Returns: 0 if found, 1 if not

# Find sidecar PIDs for a given session+root.
# Writes matching PIDs to stdout, one per line.
# Uses pgrep -x nbs-sidecar + cmdline check. No pgrep -f.
nbs_sc_find_pids <session> <root>

# Count sidecars for a session+root.
nbs_sc_count <session> <root>
# Returns: count on stdout

# Check if a sidecar PID has a healthy loop parent.
nbs_sc_has_loop <pid>
# Returns: 0 if healthy loop exists, 1 if orphaned
```

### Handle and Session Extraction

```bash
# Extract agent handle from nbs-ts session name.
# Handles are single words — stops at first hyphen after nbs-.
nbs_sc_extract_handle <session-name>
# Writes handle to stdout

# Find alive nbs-ts session by exact name.
# Replaces nbs-sidecar-find-session script.
nbs_sc_find_session <session-name>
# Writes session ID to stdout, returns 1 if not found
```

### PID File Management

```bash
# Remove stale sidecar PID file.
nbs_sc_clean_pid <handle> <root>

# Remove all sidecar PID files for a project.
nbs_sc_clean_all_pids <root>
```

### Loop Script Generation

```bash
# Generate a sidecar loop script.
# Builds the script line-by-line using arrays. No heredoc.
# Writes the script path to stdout.
#
# The generated script:
#   - Runs the sidecar with the given args
#   - On crash: checks session liveness, restarts if alive
#   - On session death: searches for replacement by exact session name
#   - Logs all events to <root>/.nbs/sidecar-loop-<handle>.log
#   - Self-deletes on clean exit (or via trap on unexpected exit)
#
# Arguments passed as an associative array:
nbs_sc_generate_loop \
    --sidecar-bin=<path> \
    --handle=<handle> \
    --root=<root> \
    --session=<session-id> \
    --session-name=<full-name> \
    --log=<log-path> \
    [--initial-prompt=<prompt>]
# Writes script path to stdout

# Launch a sidecar with a loop (generate + exec).
# Convenience wrapper: generates script, launches via setsid, returns PID.
nbs_sc_spawn <same-args-as-generate-loop>
# Writes PID to stdout
```

### Kill and Restart

```bash
# Kill a sidecar and its loop for a given handle+root.
# Kills loop first (prevents respawn race), then sidecar.
# Cleans PID file.
nbs_sc_kill <handle> <root>

# Kill and respawn a sidecar.
nbs_sc_restart <handle> <root>
```

## Code Generator Design

The loop script generator builds the script as an indexed array of lines:

```bash
nbs_sc_generate_loop() {
    local sidecar_bin="" handle="" root="" session="" session_name="" log="" prompt=""
    
    # Parse named arguments
    local arg
    for arg in "$@"; do
        case "$arg" in
            --sidecar-bin=*) sidecar_bin="${arg#*=}" ;;
            --handle=*)      handle="${arg#*=}" ;;
            --root=*)        root="${arg#*=}" ;;
            --session=*)     session="${arg#*=}" ;;
            --session-name=*) session_name="${arg#*=}" ;;
            --log=*)         log="${arg#*=}" ;;
            --initial-prompt=*) prompt="${arg#*=}" ;;
        esac
    done
    
    # Validate required args
    [[ -n "$sidecar_bin" && -n "$handle" && -n "$root" && -n "$session" ]] || return 1
    
    local script_file
    script_file=$(mktemp /tmp/nbs-sidecar-loop.XXXXXX.sh)
    
    # Build the sidecar command as a properly quoted array
    local -a sidecar_cmd=(
        "$sidecar_bin"
        "--handle=$handle"
        "--root=$root"
        "--transport=ts"
        "--log=$log"
    )
    [[ -n "$prompt" ]] && sidecar_cmd+=("--initial-prompt=$prompt")
    
    # Quote each element for the generated script
    local sidecar_cmd_str=""
    local elem
    for elem in "${sidecar_cmd[@]}"; do
        sidecar_cmd_str+="$(printf '%q ' "$elem")"
    done
    
    local nbs_ts_bin
    nbs_ts_bin=$(command -v nbs-ts 2>/dev/null || echo "$(dirname "$sidecar_bin")/nbs-ts")
    local find_session_bin
    find_session_bin=$(command -v nbs-sidecar-find-session 2>/dev/null || echo "$(dirname "$sidecar_bin")/nbs-sidecar-find-session")
    
    local logfile="${root}/.nbs/sidecar-loop-${handle}.log"
    
    # Generate the script line by line
    local -a lines=()
    lines+=('#!/bin/bash')
    lines+=("CURRENT_SESSION=$(printf '%q' "$session")")
    lines+=("LOGFILE=$(printf '%q' "$logfile")")
    lines+=('log() { echo "$(date -u "+%Y-%m-%dT%H:%M:%SZ") $*" >> "$LOGFILE"; }')
    lines+=("log \"sidecar-loop started for ${handle} session=\$CURRENT_SESSION pid=\$\$\"")
    lines+=("trap 'rm -f $(printf '%q' "$script_file")' EXIT")
    lines+=('while true; do')
    lines+=("    log \"starting sidecar session=\$CURRENT_SESSION\"")
    lines+=("    ${sidecar_cmd_str} --session=\"\$CURRENT_SESSION\"")
    lines+=('    rc=$?')
    lines+=("    log \"sidecar exited rc=\$rc session=\$CURRENT_SESSION\"")
    lines+=("    if $(printf '%q' "$nbs_ts_bin") status \"\$CURRENT_SESSION\" 2>/dev/null | grep -q \"alive\"; then")
    lines+=('        log "session $CURRENT_SESSION alive, restarting in 5s"')
    lines+=('        sleep 5')
    lines+=('        continue')
    lines+=('    fi')
    lines+=("    log \"session \$CURRENT_SESSION dead, searching for replacement\"")
    lines+=("    NEW_SESSION=\$($(printf '%q' "$find_session_bin") $(printf '%q' "$session_name"))")
    lines+=('    if [[ -n "$NEW_SESSION" ]]; then')
    lines+=('        log "found replacement session $NEW_SESSION"')
    lines+=('        CURRENT_SESSION="$NEW_SESSION"')
    lines+=('        sleep 5')
    lines+=('        continue')
    lines+=('    fi')
    lines+=('    log "no replacement session — exiting"')
    lines+=('    break')
    lines+=('done')
    
    # Write the script
    printf '%s\n' "${lines[@]}" > "$script_file"
    chmod +x "$script_file"
    
    echo "$script_file"
}
```

Key properties:
- **No heredoc.** Every line is an element in an array. Written with `printf '%s\n'`.
- **`printf '%q'` only on data values**, never on variable references like `$CURRENT_SESSION` that must expand at runtime.
- **The `--session=` argument is always outside any `printf '%q'` call** — appended directly as `--session="$CURRENT_SESSION"`.
- **Trap-based cleanup** — the script deletes itself on any exit (clean or crash).
- **The script file persists while running** — available for debugging. Read it, check the quoting, see exactly what will execute.
- **Session re-discovery uses `nbs-sidecar-find-session`** — scoped to exact session name, no cross-project contamination.

## Migration Order

### Step 1: Write `nbs-sidecar-lib.sh`

Create the library with all functions. Unit test each function independently. Do not modify any callers yet.

**Test:** Script that sources the library and calls each function with known inputs, verifying outputs.

### Step 2: Migrate `nbs-sidecar-restart` — discovery functions

Replace inline `pgrep` + `grep -qz` / `tr '\0' '\n'` patterns with `nbs_sc_find_pids`, `nbs_sc_count`, `nbs_sc_cmdline_has`. Replace handle extraction regex with `nbs_sc_extract_handle`.

**Test:** Existing `test_sidecar_restart_pid.sh` still passes.

### Step 3: Migrate `nbs-sidecar-restart` — loop generator

Replace both heredoc generators (restart_running and respawn_missing) with `nbs_sc_generate_loop` / `nbs_sc_spawn`.

**Test:** Generate a loop script, verify it contains correct content. Run it against a live session.

### Step 4: Migrate `nbs-claude` — loop generator

Replace the heredoc in nbs-claude with `nbs_sc_spawn`.

**Test:** Launch an agent, verify sidecar starts and heartbeats.

### Step 5: Migrate `nbs-sidecar-restart` — PID cleanup

Replace inline `rm -f` with `nbs_sc_clean_pid`.

### Step 6: Absorb `nbs-sidecar-find-session`

Move the logic into `nbs_sc_find_session` in the library. Keep the standalone script as a thin wrapper that sources the library and calls the function (backward compatibility for existing loop scripts).

### Step 7: Delete dead code

Remove all inline implementations that have been replaced by library calls. Verify no caller has its own version of any library function.

## Verification

After each step:
1. `bash -n` on all modified scripts
2. Existing sidecar tests pass
3. `/sidecar <handle>` works on a live project
4. No new sidecar-loop scripts in /tmp that use the old heredoc pattern

After all steps:
1. `grep -r 'pgrep -f.*nbs-sidecar' bin/` returns zero results (except the library)
2. `grep -r 'grep -qz' bin/` returns zero results
3. `grep -r 'LOOP_EOF' bin/` returns zero results (no heredoc loop generators)
4. Three teams running for 24 hours with random sidecar kills — all self-heal

## Falsification

This refactor fails if:
- Any sidecar operation still has duplicated logic after step 7
- A new sidecar bug requires fixing in more than one place
- The library introduces a regression that existing tests don't catch
- The generated loop scripts are harder to debug than the heredoc versions (they should be easier — the file persists and is readable)
