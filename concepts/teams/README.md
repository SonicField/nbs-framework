# NBS Teams Concepts

Concepts specific to multi-agent AI teams. These build on the [base NBS concepts](../) (falsifiability, goals, verification cycle) but apply specifically to teams of agents working together.

## Relationship to Base Concepts

The base concepts define *how to reason*: falsifiability, goals, rhetoric, verification. They apply to any agent, solo or in a team.

The teams concepts define *how to work together*: coordination patterns, shared practices, team-specific guides. They reference the base concepts but add the multi-agent dimension — single builder rules, phase ordering, assessment before action, honest reporting across agents.
